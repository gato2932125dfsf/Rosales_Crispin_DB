03 Implementación

Control de Concurrencia · Seguridad · Backup · Replicación

T09Semana 9

Guía de Desarrollo Académico, Componentes de Base de Datos II

En esta semana vamos a abordar los siguientes temas clave que marcan la pauta del curso de Base de Datos II. Nos enfocaremos en dos frentes de trabajo: el análisis normativo de nuestro documento guía y la inmersión en la programación y optimización avanzada de sistemas de gestión de bases de datos.

Ninguna Actividad de Momento
T10Semana 10

Administración Esencial de SQL Server | Reglamento de Grados y Títulos

Se inicia con la comprensión de cómo SQL Server organiza físicamente los datos en disco, desde las páginas y extensiones hasta los distintos tipos de archivos que componen una base de datos. A partir de esa base, se exploran las propiedades y configuraciones que determinan el comportamiento de cada base de datos, incluyendo los modelos de recuperación Simple, Full y Bulk-Logged, los cuales definen qué tan preparados estamos ante una posible pérdida de datos.

Ninguna Actividad de Momento
T11Semana 11

Seguridad y Control de Acceso en SQL Server: Autenticación, Roles, Cifrado y Auditoría aplicados al Sistema GradosTitulos

La seguridad en una base de datos no es un componente opcional, sino un pilar fundamental que determina la confiabilidad de cualquier sistema de información. En esta semana se abordan los mecanismos de seguridad que SQL Server ofrece para proteger la base de datos GradosTitulos, la cual gestiona información académica y administrativa sensible relacionada con los procesos de grados y títulos de la universidad.

Ninguna Actividad de Momento
T12Semana 12

Políticas de Backup, Planes de Mantenimiento y Recuperación ante Desastres (DRP) en GradosTitulos

El objetivo central consistió en diseñar y automatizar una estrategia robusta de seguridad informática mediante el uso avanzado de comandos BACKUP DATABASE y RESTORE DATABASE en Microsoft SQL Server. Durante el desarrollo de las actividades, se implementó una política cíclica de copias de seguridad combinando respaldos completos, diferenciales y de registros de transacciones (Log Backups), optimizando el espacio de almacenamiento y minimizando la pérdida potencial de datos.
